## 📌 Sobre o projeto

Este projeto consiste na criação de um **protótipo do site do Itaú**, desenvolvido com o objetivo de estudar e testar elementos de design de interfaces.

Durante a atividade, foram exploradas diferentes possibilidades de **cores, fontes e organização visual**, buscando compreender como esses elementos podem ser utilizados na construção de uma página web.

O protótipo representa uma etapa inicial do desenvolvimento de um site, permitindo visualizar a aparência e a disposição dos componentes antes da implementação em código.

> ⚠️ **Observação:** Este projeto é apenas um protótipo para fins educacionais e não representa um site oficial do Itaú.

---

## 🎨 O que foi desenvolvido

* 🖥️ Protótipo visual de uma página inspirada no site do Itaú.
* 🎨 Testes com diferentes combinações de cores.
* 🔤 Experimentação de fontes e estilos de texto.
* 📐 Organização de elementos para melhorar a apresentação da interface.
* 💡 Exploração de ideias de design para uma possível página web.

## 🎯 Objetivo da atividade

O objetivo foi desenvolver conhecimentos básicos de **prototipagem e design de interfaces**, compreendendo como uma ideia pode ser transformada em uma representação visual antes de ser programada.

A atividade também permitiu experimentar diferentes estilos e observar como as escolhas de cores e fontes influenciam a aparência de um site.

---

## 📚 Aprendizados

Com este projeto, foi possível aprender mais sobre:

* A importância do planejamento visual antes da programação.
* A utilização de cores para criar uma identidade visual.
* A escolha de fontes para melhorar a leitura e a apresentação.
* A organização de elementos em uma interface.
* O uso do Figma para criar e testar protótipos.
